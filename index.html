📌 A. Pengertian Data

Data adalah sekumpulan fakta, angka, keterangan, atau informasi yang diperoleh melalui pengamatan, pengukuran, pencatatan, maupun kegiatan lainnya.

Contoh Data di Sekitar Murid SMP:
  • Data nilai ulangan harian Informatika
  • Data hobi dan makanan favorit teman sekelas
  • Data jumlah uang jajan harian
  • Data tinggi dan berat badan siswa
  • Data ekstrakurikuler yang diikuti
🔍 B. Pengertian Analisis Data

Analisis Data adalah proses mengumpulkan, memeriksa, mengelompokkan, mengolah, dan menafsitkan data untuk mendapatkan informasi yang bermanfaat.

Studi Kasus: Mengetahui ekstrakurikuler yang paling diminati kelas 8.
  1. Mengumpulkan data pilihan ekskul murid.
  2. Mengelompokkan pilihan (Pramuka, Futsal, Musik, Coding).
  3. Menghitung jumlah peminat setiap ekskul.
  4. Menyajikan dalam bentuk grafik/tabel.
  5. Menarik kesimpulan: Ekskul paling populer adalah Futsal!

📂 C. Macam-Macam Data

1. Data Kualitatif

Data berupa kategori, sifat, kata-kata, atau keterangan (bukan angka).

Contoh: Hobi, warna kesukaan, makanan favorit, jenis kendaraan ke sekolah.
2. Data Kuantitatif

Data berbentuk angka yang dapat dihitung atau diukur secara pasti.

Terbagi menjadi 2 jenis: Diskrit & Kontinu.
a. Kuantitatif Diskrit

Data hasil menghitung, berupa bilangan bulat utuh.

Contoh: Jumlah buku (5 buah), jumlah komputer (20 unit), jumlah saudara (2 orang).
b. Kuantitatif Kontinu

Data hasil mengukur, dapat memiliki nilai desimal/pecahan.

Contoh: Tinggi badan (155,5 cm), berat badan (45,7 kg), suhu tubuh (36,6 °C).

📊 KENALAN DENGAN MICROSOFT EXCEL

Aplikasi spreadsheet andalan untuk mengolah data secara otomatis!

💡 Apa Itu Microsoft Excel?

Microsoft Excel adalah aplikasi perangkat lunak lembar kerja (spreadsheet) yang digunakan untuk memasukkan, menyimpan, mengatur, menghitung, dan menganalisis data dalam bentuk baris dan kolom.

⚙️ Kegunaan Utama Excel:
  • Mengolah dan merekap nilai siswa.
  • Mencatat daftar penjualan kantin sekolah.
  • Mengelola keuangan kas kelas.
  • Menghitung rata-rata, nilai tertinggi, dan terendah otomatis.
  • Membuat grafik visualisasi data.

📖 Istilah Penting Excel (Klik Card untuk Detail)

🖥️ Bagian-Bagian Antarmuka Excel

  • 📌 Title Bar: Judul dokumen
  • 📌 Quick Access: Pintasan tombol
  • 📌 Ribbon: Kumpulan menu & alat
  • 📌 Name Box: Alamat sel aktif (misal A1)
  • 📌 Formula Bar: Tempat ketik rumus
  • 📌 Column Heading: Nama Kolom (A, B, C)
  • 📌 Row Heading: Angka Baris (1, 2, 3)
  • 📌 Cell Area: Area lembar kerja

💾 EXCEL SEBAGAI TEMPAT MENYIMPAN DAN FILTER DATA

Mengatur ribuan data dengan rapi dan mencari informasi dengan cepat!

📋 Cara Membuat Tabel di Excel:
  1. Masukkan data secara terstruktur pada kolom dan baris.
  2. Blok seluruh data yang ingin dijadikan tabel.
  3. Klik menu Insert > pilih Table.
  4. Centang pilihan "My table has headers" lalu klik OK.

🧮 FUNGSI SUM: MENJUMLAHKAN DATA CEPAT

💡 Apa Itu SUM?

Fungsi SUM digunakan untuk menjumlahkan sekumpulan data angka dalam rentang (range) tertentu secara otomatis.

Perbandingan:
Tanpa SUM: =A1+A2+A3+A4+A5+A6+A7+A8 (Lama & Rawan Salah)
Dengan SUM: =SUM(A1:A8) (Cepat & Praktis!)

📈 FUNGSI AVERAGE, MIN, DAN MAX

📊 AVERAGE

Menghitung rata-rata angka.

=AVERAGE(B2:B6)

🔻 MIN

Mencari nilai terkecil/terendah.

=MIN(B2:B6)

🔺 MAX

Mencari nilai terbesar/tertinggi.

=MAX(B2:B6)

🎮 Praktik Langsung Analisis Nilai

Isilah sel B7 dengan =AVERAGE(B2:B6), B8 dengan =MIN(B2:B6), dan B9 dengan =MAX(B2:B6).

🔀 FUNGSI IF: AJARI EXCEL MEMBUAT KEPUTUSAN

💡 Penjelasan Fungsi IF

Fungsi IF digunakan untuk menghasilkan nilai berdasarkan pengujian kondisi logis (Benar / Salah).

Rumus IF Sederhana:
=IF(B2>=75, "Lulus", "Belum Lulus")

Artinya: Jika nilai di sel B2 lebih besar atau sama dengan 75, maka hasilnya "Lulus", jika kurang maka "Belum Lulus".
